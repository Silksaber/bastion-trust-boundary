# Contributing

This repository is exported from Bastion's private product repository. Each export
replaces every file here, so a change made only in this repository is overwritten by
the next one.

## What helps most

- **Security reports.** See [`SECURITY.md`](SECURITY.md).
- **Issues.** A permission you think is broader than it needs to be, an escape attempt
  the adversarial repository does not try, a claim in a README that the code does not
  support, or a file that differs from what the product gave you.

## Pull requests

A pull request is welcome as a way to show a change precisely. We do not merge it
here. If we take the change, we apply it in the product repository and it arrives in
the next export, with credit to you in the commit.

By opening a pull request you agree that your contribution is licensed under the
Apache License 2.0 and you certify the
[Developer Certificate of Origin](https://developercertificate.org/). Sign your commits
with `git commit -s`.
